Build N.6:

1. **Saving.** New tables `monster_saves` (one row per student: the `WorldState` as JSON plus a version number and a saved-at time) and `monster_events` (what happened since the last save: battles with their actions and random numbers, catches, badges, chests). Students can't write to them directly. A new `monster` server function takes a save and its events and checks them before accepting. Save at healing spots (nurse and Healing Centre), after a Tower battle, on getting a badge, and every few minutes of play. Keep the latest save on the device too until the server has it (a queue like Gem Keep's, so a Chromebook that drops the wifi loses nothing). On opening the game: load the server save, or the device one if it is newer, or start a new game (the start box from the test page, but without the test controls). Switching Chromebooks must give the same team.
2. **The server check** (plausibility, not a full replay of the whole game, same reasoning as Gem Keep): replay each reported battle with `replayBattle` and refuse a save whose team, exp, levels or items don't match what the battles allow; levels can't jump; a catch needs a right answer; a badge needs a won Tower battle at the far-half bands; chests and trainer prizes only once; answers per minute must be humanly possible; the team is 1 to 6; seen and owned only grow. Answers go in as answer events (the per-answer saving from Mission Control stage M.1) so a student's records stay right across games. Decide what to do with a bad save (refuse it, keep the last good one, tell the student nothing scary, tell the teacher page) and write that down. Add tests for each refusal.
3. **Points** inside the shared 40-a-day bot-game cap: my pick from the plan is 1 point per 3 wild battles won, 3 per trainer, 8 for a Tower badge (first time only). The game is `ranked: false`. Make the numbers one easy-to-edit block and say how many points a normal session earns.
4. **Achievements** (about 8): first catch, 10 / 25 / 54 monster-book entries, each badge (or one per badge if the list allows), all six badges, a fully evolved team. Same list and look as the other games.
5. **Leaderboard**: most monsters collected (owned entries), top 10 plus you, like Gem Keep's stars board. New season keeps the adventure and resets only the points.
6. **Teacher page**: topics on or off for the school (a switched-off topic's questions are swapped for the nearest topic that is on, so no area is ever blocked; check every battle and catch path), a per-topic view of each student's progress and the class's hardest questions (reuse Gem Keep's panel), and the game on/off switch. Real names show the way the other teacher pages show them.
7. **Wire it in** to the dashboard and game registry as a card like the other games (name, icon, sound switch, how-to-play link comes in N.7), behind the game switch, **off by default** until I say go live. Replace the test page's "Start again" and teleport buttons with nothing in the real game; keep them on the test page only.
