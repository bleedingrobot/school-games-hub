Did the fixes make the maths games better?

The Foundational maths games were reviewed again with the same method, criteria and scoring as the first review on 7 November. This page puts the two side by side.

Summary Scores What moved First-review issues New issues Newer games Live data

In short

Yes, the work improved the seven older games. Before, only Weka met the go-live bar of a 3 on every line. Now six of the seven do. Only Kiwi's Beanstalk is still under it, because its sum still moves by the calendar, not by what the child knows. No first-review issue got worse.

Read the rise with care. About 15 of the 21 points gained are real changes: mistakes that teach, help per fact, longer ladders and the teacher grid. About 6 are partly a kinder reading of the rubric, which allows "one or two loopholes" at a 3. Weka's and Tūī's Support fell from 4 to 3 only because this review asked for a demo for each new kind of go.

The five newer games have no earlier score. Four meet the bar. Robin's Berry Basket does not. Kingfisher's Dairy is not built yet, so it is not scored.

The classes have not played since the fixes went live on the weekend, so the live data can't show the effect yet.

What still matters most

1. Robin's cards can be beaten by a pattern

Tapping the third card is right about 95% of the time. It passes the step without any counting, so the game moves children on without the idea.

2. "Now you try" can be copied

A new problem caused by the fixes, in every game. Look-together shows the answer, then the redo asks the same question with the same cards. In Robin and Parrot the right card is even marked.

3. No demo for new kinds, and teachers can't see five games

No game shows a child how a new kind of go works the first time it appears. Pigeon, Parrot, Lizard, Swamp Hen and Robin are missing from the class grid and Today alerts.
