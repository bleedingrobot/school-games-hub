# src/kit: shared screens for the games

Rules (docs/plans/GAME-KIT-PLAN.md section 3): no game words in here; a change is its own small branch and PR; a game moves onto a part only when it is next touched, and nothing a child sees may change by accident. docs/kit/README.md (K2) will hold the full catalogue; until it lands, this is the list.

Every picture is SVG, takes a required `label` (the words a screen reader says; never give away an answer still being worked out), and takes colours as props (`colors={{ highlight: 'var(--wk-gold)' }}`) or as CSS variables on a parent (`--kit-highlight`). With neither it uses the text colour (`currentColor`).

- **`TenFrame`**: rows x cols of squares (default 2 x 5). Each square is `filled`, `highlight` (ring and accent), `extra` (own colour, dot inside), `empty` (dashed space) or `faint` (ghost counter). `frameSquares({ filled: 8, highlight: 2 })` builds the list. Lifted from Tūī `art.tsx` and Weka `Pebbles.tsx`, without their painted berries and pebbles.
- **`NumberLine`**: any range (0 to 20, 40 to 50, 0 to 1000), small marks (`step`, `labelEvery`), `landmarks` (the middle, the tens, a rock; `label: null` leaves one unlabelled), `arcs` (jumps above or below, with a label) and `points` (a dot or ring, with a label such as `?`). `lineX` and `lineTicks` give a game the same positions for drawing; `valueAtX` is the other way round (where a tap landed, as a value). A `lens` ({ from, to, step, landmarks, points }) adds a zoomed second line under the first that shows only that gap, joined to it by two dashed guide lines. `onPick(value)` makes the line tappable and reports the value under the tap (on the lens when there is one, unless `pickOn="line"`); the game decides what is close enough. A `LinePoint` can take a `tone` (`point`, `landmark`, `arc`...) so a guess and a true place can be different colours.
- **`DotPicture`**: dots in a box you size, an optional frame of squares behind them, `mode="groups"` to outline and colour natural groups, `tintGaps` and `ghosts` for the empty squares. `gridDots(rows, cols, w, h, gap)` gives neat rows for arrays. Lifted from Quick looks `PictureSvg.tsx`, minus the die, which stays there.
- **Junior bits (K4)**: `HearAgain` (`<prefix>-button`), `PointingHand` and `pointedLabel` (`<prefix>-hand`), `useGuidedFirstGo(guided, ms)` (`pointing`, `start`, `stop`), `WhatsNext` (the end-of-round panel), `FirstTimeTip` (a helper's tip card, Star Trader's `TipCard` with its words passed in). `voiceLinesSuite(game, allVoiceLines)` is test code in `voiceLinesSuite.ts` (not in the index). Lifted from Weka, Penguin Pairs and Star Trader; Weka uses all but `FirstTimeTip`.

Used by: Weka (the junior bits); the pictures: nothing yet. Next: the new games N1 (`NumberLine`), N3 and N5 (`TenFrame`), N4 (`DotPicture` arrays). Old games stay as they are until an R-plan next touches them.
