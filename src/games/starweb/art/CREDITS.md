# Star Web art

Painted by James on his PC with ComfyUI (docs/STARWEB-ART-PLAN.md, docs/starweb-art/config.json). Until a picture is
painted, the game draws its own night sky and uses Class Live's painted night sky (src/games/classlive/art/paint/back).
The home card stand-in is a copy of Class Live's Star Web card (src/games/classlive/art/paint/pick/stars.webp).
