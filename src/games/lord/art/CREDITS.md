# Dragon Maths pictures

The painted pictures in this folder were made for this game by James (the teacher who runs School Games Hub) with an
image AI, from the prompts in [docs/lord-art/PROMPTS.md](../../../../docs/lord-art/PROMPTS.md), then cropped, shrunk and
cut out with `scripts/lord-art.py`. They were not copied from any game, artist or art pack.

| Folder | What | Made | Tool |
|---|---|---|---|
| scenes/ | Places and the kingdom map | (filled in as pictures arrive) | |
| people/ | Village people and the three hero classes | | |
| masters/ | The eleven masters | | |
| monsters/ | 120 forest monsters | | |
| dragon/ | Scorchtail | | |

Older pictures still in the game (until each painted one arrives) are Kenney's 1-Bit Pack (CC0, see ../KENNEY-LICENSE.txt).
