# Chess piece pictures

The "cburnett" chess pieces, drawn by Colin M.L. Burnett, as packaged in the chessground
project (https://github.com/lichess-org/chessground, `assets/chessground.cburnett.css`).
They are used under the GNU General Public License (https://www.gnu.org/licenses/gpl-3.0.html).
The only change is that each picture now scales to any size.
